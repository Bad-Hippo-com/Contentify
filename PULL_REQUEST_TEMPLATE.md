# Pull Request

Bitte beschreibe kurz den Fehler oder das Ziel, die Änderung und deinen Testnachweis.

Checkliste:

- [ ] Der Code hält die im Projekt verwendeten PSR-Regeln ein.
- [ ] Zielbranch ist `main`, sofern im Issue nichts anderes vereinbart wurde.
- [ ] Ein zugehöriges Issue ist verlinkt.
- [ ] Neue oder geänderte Abläufe wurden getestet.
- [ ] Keine Passwörter, Tokens, Cookies oder sonstigen Zugangsdaten wurden eingecheckt.
- [ ] `README.md`, `bugs.md`, `todo.md`, `porting.md` und
      `PROJECT_DOCUMENTATION.md` wurden bei Bedarf aktualisiert.
